# Basic Chatbot 🤖

## About the Project
A simple rule-based chatbot developed using Python. It interacts with users through text and provides predefined responses to common messages.

## Features
- Responds to greetings such as hello and hi.
- Answers simple questions.
- Provides a default response for unknown messages.
- Ends the conversation when the user types `bye`.

## Technologies Used
- Python
- `input()` and `print()`
- `while` loop
- `if`, `elif`, and `else` conditions

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

```bash
python chatbot.py
```

## Project Goal
To understand Python loops, conditional statements, user input, and basic chatbot logic.
